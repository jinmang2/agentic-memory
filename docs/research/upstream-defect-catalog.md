## 12. Cross-cutting patterns (findings in their own right)

Source: `/home/jinmang2/agentic_memory/docs/16-abstraction-study.md` §B; `/home/jinmang2/agentic_memory/docs/research/fidelity-round11-defect-class-sweep.md`.

1. **"Paper ≠ official code" is the rule, not the exception.** A-Mem (Ps1 dead in 2 of 3 repos), Nemori (§3.3.3 absent from the code), MemoryOS (paper constants ≠ numbers constants; lowest-heat eviction in *neither* codebase), G-Memory (§4.3's J/Ω absent; code is regex critique finetune), ACE (grow-and-refine thin: ADD-only + silently-skipped dedup), A-MAC (weights unpublished and fitted on top of defects). **Zep is the sole reverse case** — its code runs *ahead* of its paper (sagas, combined extraction). Consequence adopted as project stance: "faithful to the paper" cannot be a single target; **pinning the lineage** (preset/recipe tables: `NEMORI_PRESETS`, `MEMORYOS_PRESETS`, `ZEP_SEARCH_RECIPES`, `MEMMACHINE_PRESETS`) is the only defensible position.
2. **Dead-knob family** (values that read as configuration but are never read): A-MAC `X_train`/`y_train` + 5 more; MemMachine `QueryPolicy` ×6; MemoryOS pypi `query_keywords=set()`, `lambda_t` (all three copies), eval `R_recency`, class default `max_capacity=7`, the dead `UPDATE_PROFILE_*` prompt, Updater's own 0.5 θ; Nemori `merger.similarity_threshold`, `buffer_size_max`, `episode_max_messages`, `semantic_similarity_threshold`; ReasoningBank's dead **and inverted** MaTTS `status`; ACE's default-off analyzer. Rule adopted: **reproduce dead knobs as dead, never resurrect them** — the one violation (Nemori's 0.85 made live in our "upstream" preset) was caught in round 12 and reverted.
3. **Multiple upstream copies with different constants** ("which copy produced the number?"): MemoryOS 3 cores (pypi / chromadb / eval; 4–5 counting mcp/playground, with issue #73 as a real drift incident), A-Mem 3 repos (× plain-vs-robust inside one), Nemori v1/v4, MemMachine 2 backends × 2 harnesses, Zep in continuous drift. Round 11 formalized this as **defect class (a)**: a verdict reached by reading only one copy.
4. **"Which path did the harness actually call?"** is a distinct defect class from "what does this code do" — it is found by following call sites, not by reading files: MemMachine §4.1/§4.3 (declarative + STM=None, and neither harness runs), G-Memory's discarded failure channel and 1/3/0.0 harness constants, MemoryOS's eval driver constants (cap 10 vs 7), A-Mem plain-vs-robust.
5. **Naming across three generations** — paper rhetoric ↔ upstream engineering name ↔ our mechanism name (segment=session; Profile Memory=`semantic_memory`=`profile.py`; Local Message Partitioning=`BatchSegmenter`=`BatchPartitioner`). Most of the felt "distance from the paper" is this naming distance, not semantics; mitigation is paper §-number + original term in every organizer/stage docstring.
